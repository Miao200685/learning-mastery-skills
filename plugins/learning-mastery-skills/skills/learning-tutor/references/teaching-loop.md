# Teaching and Mastery Evidence

## Diagnose First

| Evidence | Likely issue | First response |
|---|---|---|
| Cannot state the goal | orientation gap | restate the task and ask for knowns/unknowns |
| Uses a prerequisite incorrectly | prerequisite gap | return to the prerequisite |
| Knows the idea but chooses the wrong method | selection gap | compare methods and cues |
| Method is right but execution fails | procedure or carelessness | inspect step boundaries |
| Explains words without meaning | shallow encoding | ask for example, counterexample, and mechanism |
| Solves one case only | transfer gap | change representation or context |

## Prompt Fading

Move from full worked example to partially completed example to independent problem to transfer problem. Do not keep supplying the same scaffold after the learner succeeds.

## Mastery Components

- `recall`: accurate retrieval without hints.
- `independent_application`: correct execution without help.
- `retention`: successful retrieval after a meaningful delay.
- `transfer`: correct use in a new representation or context.

Do not inflate one component from another. A fluent explanation cannot replace a delayed retrieval, and a familiar exercise cannot replace transfer.

## Feedback Quality

Feedback should identify the exact decision that failed, explain why the alternative was incorrect, and provide the next action. Avoid generic praise and broad “review this” instructions.
