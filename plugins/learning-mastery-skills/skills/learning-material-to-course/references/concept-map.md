# Concept Map Quality

## Atomicity

A concept is atomic when it can be taught, recalled, and assessed as one coherent unit. Split a concept if it has multiple learning objectives, independent procedures, or unrelated evidence requirements.

## Edge Quality

- Prerequisite: the learner cannot perform the target without it.
- Confusable: the two concepts are commonly mixed up but neither strictly requires the other.
- Related: useful association only; never use it as a prerequisite.
- Transfer: a new context where the concept should still work.

Avoid chains longer than necessary. A cycle always indicates either a wrong dependency or a concept that should be merged.

## Exam Weight

Estimate weight from supplied syllabus or past-paper evidence first. If no direct evidence exists, store an `exam_weight_estimate` separately and mark it inferred. Do not present an estimate as an official mark allocation.

## Diagnostic Design

- Cover every major cluster with at least one item.
- Start with a prerequisite or warm-up item, then a representative item, then one transfer item.
- Ask for confidence before revealing correctness.
- Record what kind of error occurred; a wrong answer alone is not enough.
- Use diagnostic results to change sequence, not to label the learner permanently.
