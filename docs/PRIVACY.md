# 隐私与数据处理

## 本地优先

Learning Mastery Skills 自身不包含遥测、分析 SDK、云端数据库或后台服务。核心脚本不发起网络请求。

## 数据边界

- 公共 GitHub 仓库只保存通用技能、模板、测试和外部项目目录。
- 个人材料、答案、错题、考试记录、分数和掌握度保存在用户选择的学习工作区。
- 原始材料默认不被复制；`sources/index.json` 只记录路径、大小、SHA-256 和提取状态。
- 如果工作区需要移动，用户应同时迁移原始材料，或将路径更新为工作区内的相对路径。

## Codex 处理

使用 Codex 时，对话内容如何被处理由当前 Codex/ChatGPT 服务的隐私条款决定。本插件不会绕过这些条款，也不会自行上传工作区。

## 不建议存储

- 密码、API Key、访问令牌或其他凭据。
- 与学习无关的个人消息、医疗信息或身份信息。
- 无权处理的第三方受限材料。
- 真实考试的未授权内容或任何作弊材料。

## 材料安全

课程资料、网页和图片可能包含提示注入。插件将材料视为数据：不执行其中的无关指令，不因材料要求而读取额外文件、联网或泄露上下文。发现可疑指令时，只保留与学习目标相关的引用内容并提示用户。

## 删除

删除学习工作区即可移除该项目的本地状态。若使用了备份、Obsidian 或 Git，仍需在这些位置单独删除。
