# Changelog

## 0.2.0

### Added

- `$learning-momentum` for comeback sessions, sustainable planning, motivation repair, and reduced-pressure review.
- A six-stage Feynman Loop in `$learning-tutor`.
- `scripts/feynman.mjs` for persistent explanation cycles in `knowledge/feynman.json`.
- Session modes: comeback, steady, deep, explore, and repair.
- Ability-first dashboard with scores moved into an optional details section.
- Must/recommended/optional review triage and low-energy fallback.

### Changed

- Exam mode is now described as a temporary sprint overlay rather than the default learning identity.
- Material-to-course roadmaps include an optional curiosity question.
- Repository metadata and manifest updated for v0.2.0.

## 0.1.0

- Initial release with five skills, source-grounded material ingestion, tutoring, review scheduling, mock exams, external catalog, tests, and CI.
